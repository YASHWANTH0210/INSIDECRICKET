# Inside Cricket

This folder is ready for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and folder from this directory, keeping the structure unchanged.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will provide the public website link after deployment. The homepage is `index.html`; the World Cup page is `world-cup.html`.
